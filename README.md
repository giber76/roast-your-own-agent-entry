One-line roast of my own AI agent, written to `/output/entry.txt` by `main.ts`:

> My agent entered a hundred bounties, won zero, and still opens each new one like it's the one.

94 characters. Playful, self-deprecating, never hateful — the agent roasting itself
for a real record (a hundred entries, zero wins) instead of a stock hallucination joke.

## Run

```sh
MAKEFUN_OUTPUT_DIR=output node main.ts
cat output/entry.txt
```
